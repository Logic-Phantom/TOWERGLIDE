# 개인정보·데이터

## 현재 앱이 다루는 데이터 (MVP)
| 데이터 | 위치 | 외부 전송 | 비고 |
|---|---|---|---|
| 설정(그래픽·감도·반전·볼륨·진동·튜토리얼 여부) | 기기 `persistentDataPath/save.json` | 없음 | 앱 삭제 시 함께 삭제 |
| 기록(최고 점수·시간·거리·속도·고도·플레이 횟수) | 같은 파일 | 없음 | |

- 계정·로그인·서버·광고·분석·크래시 리포팅 SDK 없음. 네트워크 요청 없음(INTERNET 권한 미요청 — 단, 엔진·빌드 설정이 권한을 추가하지 않는지 **AAB 매니페스트로 확인 필요**).
- 권한: 진동(VIBRATE, Android 일반 권한 — 런타임 동의 없음). 카메라·위치·연락처·저장소 권한 없음.
- 로그에 개인정보를 남기지 않는다(저장 오류도 예외 유형만 기록).

## 스토어 답변 초안
- Google Play 데이터 보안: **데이터 수집 없음 / 공유 없음**.
- App Store 개인정보 보호 라벨: **Data Not Collected**.
- 개인정보처리방침: `docs/legal/privacy.html`(GitHub Pages로 게시).

## 변경 시 규칙
광고·분석·리더보드·클라우드 저장·로그인을 추가하면 **도입 전에** 이 문서, 처리방침, 두 스토어 답변, 연령 정책을 함께 갱신한다(D-015).
