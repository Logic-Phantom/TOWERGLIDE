# 조작

## 모바일(가로, 기본)
| 위치 | 컨트롤 | 동작 |
|---|---|---|
| 화면 왼쪽 45% 아무 곳 | 플로팅 조이스틱(설정에서 고정형 전환) | X = Roll(기울기), Y = Pitch(위로 밀면 기수 상승, 설정에서 반전) |
| 오른쪽 아래 큰 버튼 | BOOST(누르고 있기) | 게이지 소모, 소진 시 25% 충전까지 잠금 |
| 그 왼쪽 | BRAKE(누르고 있기) | 에어브레이크 |
| 위쪽 | CAM / RESET | 추적 ↔ 조종석 시점 / 안전 지점 복귀 |
| 오른쪽 위 | II | 일시정지 |

- 요(Yaw)는 기울기에 따라 자동(협조 선회). 별도 러더는 고급 옵션으로 열어 둠(입력 구조상 `FlightInput.Yaw` 존재).
- 스로틀은 자동 순항. 별도 스로틀 UI는 화면이 복잡해져 MVP에서 제외(키보드/게임패드에는 있음).
- 손가락을 떼면 즉시 0. 멀티터치는 처음 잡은 손가락(pointerId)만 추적 → 오른손 버튼과 간섭 없음.
- 모든 HUD·조작 UI는 `SafeArea` 안(노치·펀치홀 회피). 캔버스 기준 1920×1080, 가로/세로 50% 매칭.
- 감도·데드존(8%)·expo(35%)는 `FlightInputRouter`에서 한 번만 적용.

## 에디터/PC 테스트
키보드: W/S 피치(W = 상승) · A/D 롤 · Q/E 요 · ↑/↓ 스로틀 · Shift 부스트 · Space 에어브레이크 · C 카메라 · R 복귀 · Esc/P 일시정지
게임패드: 왼쪽 스틱 · 숄더 요 · RT 스로틀 · LT 브레이크 · A(South) 부스트 · Y(North) 카메라 · X(West) 복귀 · Start 일시정지

## 실기기 확인 항목(미실행)
- [ ] 엄지 도달 범위(6.1"·6.7" 폰, 태블릿)
- [ ] 플로팅 vs 고정 조이스틱 — 더 안정적인 쪽을 기본값으로(명세 2.1)
- [ ] 버튼 크기(최소 9mm 이상 체감), 오입력
- [ ] 노치·펀치홀·제스처 영역 겹침(iOS는 가장자리 제스처 지연 설정 적용)
