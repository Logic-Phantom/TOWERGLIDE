# 서울 월드 성능 기록

> 애드온 명세 7.3. **측정하지 않은 FPS·로딩 시간을 성공 수치로 쓰지 않는다.** 2026-11-08 현재 측정 0건(Unity 미설치).

## 측정 방법
1. Development Build(`TOWERGLIDE ▸ Build ▸ Android APK`) → HUD 왼쪽 아래 스트리밍 디버그(현재 청크·로드/로딩/실패 수·최근/최대 로드 ms·관리 메모리)를 켠 채 비행.
2. Unity Profiler(USB 연결) — CPU·GPU·Memory·GC Alloc, `SceneManager.LoadSceneAsync` 구간 스파이크.
3. 시나리오: ① 시작 지점에서 3분 자유 비행 ② 제트(Viper F-9) 최고 속도+부스트로 도시 대각선 왕복 5회 ③ 여객기로 고고도 10분 ④ 백그라운드 전환 후 복귀.
