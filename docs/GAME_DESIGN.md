# 게임 디자인

**TOWERGLIDE(타워글라이드)** — 빌딩 사이, 한계 없이. 3D 어반 플라이트 / 아케이드 비행 액션 / 장애물 회피. 싱글·오프라인.

참고한 것은 "3D 공간을 직접 조작하며 탐험하는 재미"라는 아이디어뿐이다. 다른 작품의 코드·모델·화면·브랜드는 쓰지 않는다(명세 0.1-8). 실제 항공기 제조사 로고·도장도 쓰지 않는다.

## 핵심 재미
1. 자유 비행 — 상승·하강·선회로 도시 탐험
2. 아슬아슬한 통과 — 좁은 통로·크레인·드론·링
3. 속도와 숙련도 — 부드러운 기울기, 연속 링 콤보, 기록 갱신

## 모드 (MVP)
| 모드 | 규칙 | 구현 상태 |
|---|---|---|
| FREE FLIGHT | 목표 없음. 시간·거리·최고 속도·최고 고도 기록. 충돌 시 게임 오버 없이 최근 안전 지점(2초마다 갱신, 주변 18m 비어 있고 수평)으로 복귀. 구역 이탈 시 경고 → 계속 벗어나면 복귀. `END`로 종료 | 코드 작성(미실행) |
| SKYLINE RUN | 링 12개를 순서대로. 제한 3분. 충돌 시 마지막 링에서 재개 + 3초 감점. 링 점수·콤보·근접 회피·완주/남은 시간 보너스, 충돌 감점 | 코드 작성(미실행) |

후속: TIME ATTACK, PRECISION(무충돌), WIND CHALLENGE, NIGHT FLIGHT, 기체 스킨.

## 점수 (`ScoreRules.Default`)
링 100 · 콤보(6초 안 연속) 단계당 +25(최대 8단계) · 근접 회피 50 + 근접도×속도 최대 +100(장애물별 3초 쿨다운, 충돌한 장애물 제외) · 충돌 −150 · 완주 +1000 · 남은 1초당 +20 · 총점 0 미만 없음.

## 화면
메인 메뉴(로고·SKYLINE RUN·FREE FLIGHT·HANGAR/SETTINGS 준비 중·최고 기록) → 비행 HUD(속도·고도·부스트 게이지·모드·링 진행·타이머·점수·다음 링 화살표·토스트·경계 경고·일시정지) → 일시정지(재개·재시작·메뉴) → 결과(완주 여부·점수·링·콤보·근접 회피·충돌·시간·거리·최고 속도/고도·재도전·메뉴).

## 도시 (Phase 2)
- 11×11 블록(70m 간격), 시드 20261108, Core `CityLayoutGenerator`가 배치 — 같은 시드면 항상 같은 도시.
- 건물 아키타입 12종: 유리 타워, 콘크리트 오피스, 셋백 타워, 트윈 타워, 바늘형 첨탑, 저층 상가, 포디움+타워, 헬리패드 옥상, 물탱크 옥상, 어두운 유리 슬래브, 왕관형 꼭대기, 계단형 저층. 높이에 맞는 형태만 나온다.
- 외벽 창문은 층고 3.6m·폭 4m로 모든 건물이 정렬(미터 UV + 반복 텍스처 3종).
- 150m 이상 건물 꼭대기 경고등, 초고층 옥상 안테나(코스 여유가 있는 곳만).
- 코스 주변 건물은 자동으로 낮춤/비움, 협곡 양쪽 벽은 유지 — 둘 다 테스트로 보장.
