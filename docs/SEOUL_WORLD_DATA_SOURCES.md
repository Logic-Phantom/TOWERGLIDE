# 서울 월드 데이터 출처·라이선스 기록 (Phase OW0)

> 애드온 명세 3장. **조건이 확인되지 않은 데이터는 `PENDING_REVIEW`로 두고 다운로드·임포트·빌드에 넣지 않는다.**
> 작성 2026-11-08. 이 문서의 어떤 항목도 아직 **다운로드하지 않았다**. 현재 게임 빌드에 포함된 서울 지도·건물·지형 데이터는 **0건**이며, 도시는 전부 절차적 테스트 데이터다.

## 0. 이 프로젝트에 적용되는 전제 (명세와 다른 점)
- 애드온 명세는 "개인 학습·비상업적 프로젝트 우선"을 가정한다. 그러나 이 저장소는 **Google Play·App Store 공개 배포**를 목표로 한다(무료·광고 없음이어도 공개 배포). 따라서 판단 기준은 **"공개 배포되는 앱에 포함해도 되는가"**이다.
- 그래서 **비상업 조건(CC BY-NC, 공공누리 제2·4유형 등)이나 변경금지 조건(공공누리 제3·4유형, CC BY-ND)이 붙은 자료는 게임에 넣지 않는다.** 참고(보고 형태만 배우기)로만 쓴다.
- 확정 판단이 필요한 항목은 출시 전 법률 검토를 받는다(AI가 라이선스 적합성을 보증하지 않는다).

## 1. 판정 기준
| 상태 | 의미 |
|---|---|
| `ALLOWED` | 원문 확인 완료 + 공개 배포 앱 포함 가능 + 의무사항(출처 표시 등) 정리 완료 |
| `REFERENCE_ONLY` | 시각 참고만. 데이터·모델·이미지를 추출·포함하지 않음 |
| `PENDING_REVIEW` | 개별 데이터셋 조건 미확인 — 다운로드·임포트·빌드 금지 |
| `REJECTED` | 공개 배포 조건과 맞지 않음 |

## 2. 후보 데이터

### 2.1 OpenStreetMap (도로·건물 footprint·수역·공원)
| 항목 | 내용 |
|---|---|
| 제공 | OpenStreetMap contributors / OpenStreetMap Foundation |
| 라이선스 | Open Database License (ODbL) 1.0 — https://www.openstreetmap.org/copyright |
| 출처 표시 | `© OpenStreetMap contributors` + 저작권 페이지 링크. 표시 위치 계획: 메인 메뉴 하단 크레딧(`MainMenuController.creditsText`) + 설정 ▸ 크레딧 + 스토어 설명 |
| 공개 배포 | 상업·비상업 모두 허용(ODbL). 게임 화면 같은 "제작물(Produced Work)"은 출처 표시가 필요하고, **가공한 데이터베이스(Derivative Database)를 공개 배포하면 ODbL로 공유할 의무**가 생길 수 있다 |
| 우리 구조에서의 쟁점 | 청크 데이터 파일(건물 footprint·높이 등)을 앱에 넣으면 그 자체가 "파생 데이터베이스 배포"로 볼 여지가 있다 → 청크 데이터의 ODbL 공개(예: 저장소에 가공 데이터 공개) 또는 메시로만 굽기 중 무엇을 택할지 **법률 검토 필요** |
| 금지 | 공용 타일 서버 런타임 호출(타일 사용 정책 위반 소지). 원본 다운로드(Geofabrik 추출본 등)는 그 배포처 조건도 확인 |
| 다운로드 날짜·버전 | 미다운로드 |
| 상태 | **`PENDING_REVIEW`** — 라이선스 자체는 공개 배포 가능하나, 파생 DB 공유 방식 결정 전까지 임포트하지 않음 |

### 2.2 서울시 S-Map (Virtual Seoul 3D 디지털 트윈)
| 항목 | 내용 |
|---|---|
| 제공 | 서울특별시 — https://smap.seoul.go.kr/ , 안내 https://news.seoul.go.kr/gov/archives/528155 |
| 라이선스 | 서울시 안내 페이지에는 공공누리 제4유형(출처표시·상업적 이용금지·변경금지)이 표시되어 있다는 것이 명세의 기술. **그 표시는 해당 페이지 저작물의 조건이며, S-Map 3D 모델·데이터셋별 조건은 미확인** |
| 공개 배포 | 데이터셋별 조건 확인 전에는 판단 불가. 제4유형이라면 상업 이용·변경이 금지되어 **게임 포함 불가** |
| 상태 | **`REFERENCE_ONLY`** (도시 형태·스카이라인 참고만) + 데이터셋별로는 **`PENDING_REVIEW`**. 화면 캡처·모델 추출·자동 다운로드 금지 |

### 2.3 서울 열린데이터광장 등 공공 공간정보
| 항목 | 내용 |
|---|---|
| 제공 | 서울특별시 열린데이터광장(https://data.seoul.go.kr), 서울시 공간정보(https://english.seoul.go.kr/policy/smart-city/spatial-data/) |
| 라이선스 | **데이터셋마다 다름**(공공누리 유형 표시 확인 필요). 제1유형(출처표시)이면 공개 배포 가능성이 높고, 제2~4유형은 게임 포함 불가로 판단 |
| 상태 | **`PENDING_REVIEW`** — 사용할 데이터셋을 고른 뒤 데이터셋 단위로 기록 |

## 4. 빌드 차단 절차
1. 원본 데이터는 저장소 밖(`../TOWERGLIDE_data/raw/`)에 둔다. 저장소에는 가공 결과와 메타데이터만.
2. 가공 결과(청크 데이터)마다 `Data/SeoulWorld/ImportMetadata/<dataset>.json`에 위 표의 값과 `status`를 기록.
3. (OW2 구현 예정) 빌드 전 검증기 `SeoulWorldLicenseReportBuilder`가 `status != ALLOWED`인 데이터가 빌드 씬·Resources에 들어 있으면 **빌드를 중단**하고, 출처 표시 문구를 크레딧에 자동 반영한다.
4. 지금(OW1)은 실제 데이터가 0건이므로 크레딧 문구도 비워 둔다 — 쓰지 않은 데이터의 출처를 표시하지 않는다.
